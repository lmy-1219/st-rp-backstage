# core — 本机后台

独立 Node 进程，只听 `127.0.0.1`，零依赖（用 Node 自带的 SQLite，需 Node ≥ 22.5）。浏览器不直接连它，经 ST 里的转发插件（`plugin/`）过来。

| 文件 | 干什么 |
|---|---|
| `main.mjs` | 启动入口：`npm run core`（数据默认在 `.runtime/core/`，可用 `--home` `--port` 改） |
| `server.mjs` | HTTP 接口 `/v1/*` |
| `store.mjs` | 存储：局、窗口、消息正文（按局、按内容指纹去重）、每个窗口当前的消息序列、钉住的材料格、事件日志 |
| `slot.mjs` | 发言前给当前角色的那一格：钉住、读法句、接线测试 |
| `recall.mjs` | 那一格的内容：按角色知情过滤后组装（见下"那一格（M3）"） |
| `config.mjs` | 后台自己的配置 `<数据目录>/config.json`：抽取模型、钥匙、单价、每日花费上限、抽取前要剥掉的标记（不进仓） |
| `model.mjs` | 调 OpenAI 兼容的模型接口 |
| `extract.mjs` | 抽取：提示词、小窗切分、在场判断、引文逐字核对、结果落账 |
| `records.mjs` | 记录（证据账）与抽取任务的存储、窗口可见记录、还开着的想法 |
| `worker.mjs` | 记账调度：开了记账的窗口有定稿未记的消息就一小窗一小窗地抽；当天花费到上限就停 |
| `economy/` | 经济计算与展示（纯模块，尚未接真数据） |

## 抽取（M2）

- **只记定稿的消息**：后面已经有消息了的才算定稿；最后一条等下一条出来再记。改稿之后新版本重记，旧版本的记录自动不可见。
- **每条记录**：型（说／做／想法／改变／时间／了结）、一句话、关于谁、时态、1～2 段逐字原文、待办／对外编的／持续多久／过了多久。
- **程序填、不让模型判的**：谁的说法（＝那条消息的说话人）、当时谁在场（群成员＋在场区间）、消息顺序。
- **核对**：引文必须逐字出自那条消息（先剥 TTS 标记）；消息号必须在这一窗里；"了结"必须对得上还开着的想法。没过的记为"被拦下"，留痕不丢。
- **花钱的控制**：每个窗口要手动"开始记账"（面板里先给出调用次数与估算花费）；配置里有每日上限，到了就停。
- **坏段落**：模型输出里没转义的引号会自动修；4 条以上、两千字以上的一段一条都没记当作可疑重试（多半是碰到敏感内容整段放弃）；同一段连续失败 3 次跳过并留痕，不无限重试扣钱。
- **模型**：D-60 实测后用 `claude-opus-4-6`。新一代模型（如 Opus 5.5）思考关不掉，这类短抽取反而贵五六倍。

## 那一格（M3）

每次某个角色要发言，程序（不调模型）按下面的顺序拼几行自然语言，放进只给他的那一格：

1. **只看他知道的**：记录的"当时在场"里有他（或是他自己说的/做的）。私下对别人说的，他拿不到。
2. **和眼下有关的旧事**：用最近 3 句正文和他知道的记录按三字组比重合（常见字组降权），取最多 8 条，按时间顺序给，附原话片段和"几天前"。最近 30 条消息里的不给——前台自己看得见。用户那句里说了几件事的，一句一句也各算一遍，每句最对得上的那条先占位（D-159）。
3. **一直算数的现状**：持续期是"直到被改变""永久"的改变，和在场的人有关的优先。
4. **还开着的事**：他提的或和他有关的想法、答应过的事，了结了的不再端出来。
5. **说腻了的**：他最近 6 条回复里出现 3 次以上的说法，提醒这次不用再说。
6. **刚进场**：在场区间刚开始的，提示他不在场时的事他不知道。

相对时间只按记账里的"时间"记录推（原文明写了过去多久才算）。约 1500 字封顶。

## 几个要点

- **消息身份＝谁说的＋说了什么**（`fingerprint`）。浏览器端 `extension/sync.mjs` 用同样算法。
- **一个窗口现在有哪些消息，只看它当前的序列**。改稿、删稿、换 swipe 之后旧版本自然不可见，派生材料以后也按这个过滤。
- **同步是增量的**：浏览器先报序列（每条只有指纹），后台缺哪条正文才让它补传。788 条的窗口首次接入约 1.5 秒；之后每次只传变化的那条。
- **塌缩保护**：序列一下子少了一半以上（且少了 10 条以上）先不认，面板上让用户确认（N-51）。
- **分支**：ST 建分支会把我们的标记原样复制过去；后台看到同一标记出现在另一个聊天、且原聊天还在 ⇒ 登记为同一局的新分支，共用前缀正文。原聊天不在了 ⇒ 当作改名。
- **钉住**：同一窗口、同一角色、同一段上文 ⇒ 同一格（左滑重生成、换模型对比时材料不变）。

## 接口

| 路由 | 用途 |
|---|---|
| `GET /v1/health` | 健康检查 |
| `POST /v1/join` | 接入一个窗口（开一局新的） |
| `POST /v1/open` | 打开带标记的窗口：同一个 / 改名 / 分支 / 未知 |
| `POST /v1/sync` | 报当前序列；返回缺哪些正文，或已提交及增删条数 |
| `POST /v1/messages` | 补传正文（指纹对不上的拒收） |
| `POST /v1/slot` | 发言前要那一格 |
| `POST /v1/status` | 面板用的状态 |
| `POST /v1/enabled`、`/v1/options` | 暂停/恢复本窗口；接线测试开关 |
| `POST /v1/extract-plan` | 记账状态：配没配模型、待记多少条、估算花费、今天花了多少 |
| `POST /v1/extract-enable` | 开/关本窗口的后台记账 |
| `POST /v1/extract-run` | 立刻跑若干小窗（只给本机工具用，转发插件不放行） |
| `POST /v1/records` | 本窗口看得见的记录（或被拦下的） |
