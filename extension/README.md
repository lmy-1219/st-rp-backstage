# extension — ST 前端扩展

装在 ST 的 `data/<用户>/extensions/rp-emergence/`（开发时用 `npm run install:d` 装进测试副本）。

| 文件 | 干什么 |
|---|---|
| `manifest.json` | 扩展声明，注册生成拦截器 `rpEmergenceIntercept` |
| `index.js` | 接入窗口、消息变化时增量同步、发言前向后台要"那一格"并临时注入、设置面板 |
| `sync.mjs` | 纯函数：认说话人、算消息指纹（纯 JS SHA-256，远程 http 访问也能用）、分批 |

## 行为

- **接入**：新开的窗口（只有开场白或空的）自动接入；老窗口在面板里点"接入这个窗口"。接入只往聊天元数据里写一个小标记 `rp_emergence: {chatKey}`（约 70 字节），不存任何正文副本。
- **同步**：发送、收到、编辑、删除、左滑、群成员变化后 1.5 秒同步一次；后台连不上时每 30 秒重试。
- **注入**：只对正常生成、左滑、重新生成、续写注入；AI 帮答（impersonate）、静默生成（其他插件的后台调用）不注入。读法句放开头系统块，那一格放末尾（J-42）。生成结束、停止、切换聊天时清掉。
- **关掉就没有**：总开关关闭、本窗口暂停、后台连不上时，什么都不塞，ST 照常用（N-40）。

- **后台记账**：面板里显示这个窗口待记多少条、全记一遍约几次调用和多少钱；点"开始记账（会花钱）"会再弹一次确认。"看看记住了什么"列出每条记录、原文片段、谁的说法、当时谁在场；"被拦下的"列出没通过核对的。

面板在 ST 扩展设置里的"RP：幕后"。
